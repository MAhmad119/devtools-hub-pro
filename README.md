# ⚡ DevTools Hub - Fast Developer & Designer Utility Suite

DevTools Hub is a high-performance, dark-mode client-side utility suite built for developers, designers, and tech professionals. 

## 🛠️ Built-in Tools
- 🔐 **Secure Password Generator:** Generate custom-length cryptographic passwords and API keys instantly.
- 💻 **JSON Beautifier & Validator:** Format, clean, and validate raw JSON objects securely in-browser.
- 🛡️ **Base64 Encoder / Decoder:** Lightning-fast text encoding and decoding utilities.
